# AouPlr

Welcome to **AouPlr**, your ultimate academic companion!

**AouPlr** is designed to make managing your academic life both intuitive and efficient, built with cutting-edge tools and a user-centric design. Whether you're tracking courses, calculating your GPA, or accessing helpful study resources, **AouPlr** is here to support you on your academic journey every step of the way.

## Features

- **Course Management**: Track your courses, view exam dates, and manage your study plans effortlessly.
- **GPA Calculator**: Easily calculate your GPA to stay informed about your academic performance.
- **Study Resources**: Access helpful guides and course materials to aid your studies.
- **Exam Date Conflict Resolution**: Report and resolve exam date conflicts quickly.
- **Responsive Design**: Enjoy a clean, responsive, and accessible interface on all devices.
- **Offline Access**: As a Progressive Web App (PWA), **AouPlr** can be accessed offline and installed on your device for quick, app-like functionality.

## Technologies Used

- **Next.js**: Provides fast, seamless navigation and server-side rendering for optimal performance.
- **React**: Enables building a dynamic and interactive user interface.
- **MDX**: Integrates Markdown and JSX to create rich, interactive content within markdown files.
- **Node.js**: Offers reliable server-side operations ensuring smooth backend functionality.
- **TailwindCSS**: A utility-first CSS framework used for styling the application.
- **DaisyUI**: Enhances TailwindCSS with pre-designed components for a better UI experience.
- **TypeScript**: Adds static typing to JavaScript, improving code quality and maintainability.
- **Progressive Web App (PWA)**: Allows the app to function offline and be installed on devices.
- **pnpm**: Utilized for optimized package management.

## Project Structure

- **Pages**: Main application pages such as home, guides, and course tools.
- **Components**: Reusable UI components including the navbar and theme selector.
- **Lib**: Contains server-side functions and utilities for data fetching and processing.
- **Public**: Static files like icons, images, and the manifest file for PWA functionality.
- **Data**: Includes guides and materials essential for academic support.
- **Styles**: Contains TailwindCSS configurations and custom styles.

## Getting Started

To start using **AouPlr**:

1. **Installation**: Clone the repository and install the dependencies using your preferred package manager (`npm`, `yarn`, or `pnpm`).
2. **Development Server**: Run the development server to start using the app locally.
3. **Build**: Generate an optimized production build when ready to deploy.

**Note**: Ensure that you have **Node.js** installed on your machine.
